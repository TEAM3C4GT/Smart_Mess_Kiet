# KF-MANAGEMENT

Smart Mess & KFC Management System

This repository contains the foundation for the Smart Mess & KFC Management System, which solves the unpredictability of student meal attendance and tracks food court pre-orders.

## Architecture

- **mess-api**: Node.js + Express + MongoDB application layer
- **mess-web**: React + shadcn/ui + Recharts frontend
- **mess-ai-service**: Python FastAPI AI forecasting and NLP service
